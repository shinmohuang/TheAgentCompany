# 使用开源模型的快速开始指南

这是一个简化版指南，帮助您快速上手使用开源模型进行 TheAgentCompany 评测。

## 🎯 三步快速开始

### 第一步：部署模型服务

选择以下任一方式：

#### 方式 A: vLLM（推荐，性能最好）

```bash
# 1. 使用提供的脚本快速启动
cd /home/hxm826/TheAgentCompany
bash scripts/start_vllm.sh "Qwen/Qwen2.5-72B-Instruct" 8000 1

# 参数说明:
# - Qwen/Qwen2.5-72B-Instruct: 模型名称
# - 8000: 端口号
# - 1: GPU 数量
```

#### 方式 B: Ollama（最简单）

```bash
# 1. 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 2. 下载并运行模型
ollama pull qwen2.5:72b
ollama serve  # 会在 11434 端口启动
```

#### 方式 C: 使用云端 API（无需本地 GPU）

注册任一服务并获取 API key：
- Together AI: https://api.together.xyz/
- Groq: https://console.groq.com/
- DeepInfra: https://deepinfra.com/

### 第二步：测试模型 API

```bash
# 测试本地模型服务
cd /home/hxm826/TheAgentCompany
bash scripts/test_model_api.sh "http://localhost:8000" "Qwen/Qwen2.5-72B-Instruct"

# 如果使用 Ollama:
# bash scripts/test_model_api.sh "http://localhost:11434" "qwen2.5:72b"
```

如果看到 "✅ API 测试成功!"，说明模型服务正常。

### 第三步：配置并运行评测

```bash
# 1. 编辑配置文件（已经为您预配置好了）
nano evaluation/config.toml

# 2. 确保服务正在运行
# RocketChat: http://localhost:3002
# GitLab: http://localhost:8929
# Plane: http://localhost:8091
# OwnCloud: http://localhost:8092

# 3. 运行快速评测脚本
sudo bash scripts/quick_eval_opensource.sh
```

## 📝 配置文件说明

您的 `evaluation/config.toml` 已经配置好了基本设置：

```toml
# Agent 模型（执行任务的 AI）
[llm.group1]
model="Qwen/Qwen2.5-72B-Instruct"
base_url="http://localhost:8000/v1"
api_key="EMPTY"

# 环境模型（NPC 和评估器）
[llm.group2]
model="Qwen/Qwen2.5-72B-Instruct"
base_url="http://localhost:8000/v1"
api_key="EMPTY"
```

### 根据您的部署方式修改：

**如果使用 Ollama:** （⚠️ 需要 openai/ 前缀）
```toml
model="openai/qwen2.5:72b"
base_url="http://localhost:11434/v1"
api_key="ollama"
```

**如果使用 Together AI:** （不需要前缀）
```toml
model="meta-llama/Meta-Llama-3.1-70B-Instruct-Turbo"
base_url="https://api.together.xyz/v1"
api_key="your-api-key-here"
```

**如果使用 Groq:** （不需要前缀）
```toml
model="llama-3.1-70b-versatile"
base_url="https://api.groq.com/openai/v1"
api_key="your-api-key-here"
```

### 📌 重要规则：

- **本地部署**（vLLM, Ollama, LM Studio）：**必须**加 `openai/` 前缀
- **云端 API**（Together AI, Groq, OpenAI）：**不需要**前缀

## 🎮 评测选项

运行评测脚本后，您可以选择：

1. **完整评测**: 175 个任务，需要数天时间
2. **NPC 任务**: ~60 个需要对话的任务，更快完成
3. **单任务测试**: 先测试一个任务看效果

推荐先选择 "3. 单任务测试" 来验证设置是否正确。

## 🔍 常见问题

### Q1: 没有 GPU 怎么办？
使用云端 API 服务（如 Groq、Together AI），或者使用小模型（7B-14B）。

### Q2: vLLM 启动失败？
检查 GPU 驱动：
```bash
nvidia-smi
```

### Q3: Docker 容器无法访问 localhost？
在 config.toml 中使用 `http://host.docker.internal:8000/v1`（Mac/Windows）

### Q4: 模型响应太慢？
- 使用更小的模型
- 使用量化版本
- 增加 GPU 数量
- 使用云端快速 API（如 Groq）

### Q5: 评测中断了怎么办？
再次运行评测脚本，它会自动从上次中断的地方继续。

## 📊 推荐模型配置

### 预算充足（追求最佳性能）
- Agent: Claude 3.5 Sonnet 或 GPT-4o
- 环境: 同上

### 本地 GPU（4x A100 或更好）
- Agent: Qwen2.5-72B-Instruct
- 环境: 同上或使用 Claude 3.5 Sonnet

### 本地 GPU（2x A100）
- Agent: Qwen2.5-32B-Instruct
- 环境: Qwen2.5-32B 或 GPT-4o

### 单 GPU 或云端 API
- Agent: Qwen2.5-14B / Llama-3.1-8B / Groq API
- 环境: GPT-4o 或 Claude 3.5 Sonnet

### 极低预算
- Agent: Ollama + Qwen2.5:7b
- 环境: Groq API (免费额度) 或 同上

## 🚀 优化技巧

1. **提前构建镜像**: 避免每次评测重新构建
   ```bash
   ./evaluation/build_oh_runtime_images.sh
   ```

2. **并行运行**: 如果有多个 GPU，可以同时运行多个评测实例

3. **混合配置**: Agent 用开源模型，环境用商业 API
   ```toml
   [llm.group1]
   model="Qwen/Qwen2.5-72B-Instruct"
   base_url="http://localhost:8000/v1"
   
   [llm.group2]
   model="gpt-4o"
   base_url="https://api.openai.com/v1"
   api_key="your-openai-key"
   ```

4. **调整参数**: 根据任务复杂度调整 max_iterations 和 max_budget
